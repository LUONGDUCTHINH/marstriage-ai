as `NNNN-short-title.md` (start with `0001`) using this outline:

```markdown
# NNNN — Title

Status: Proposed | Accepted | Superseded
Date: actual decision date
Owners: responsible team members

## Context
Problem, constraints, and evidence.

## Options
Alternatives and tradeoffs.

## Decision
Selected approach and rationale; keep proposed choices clearly marked.

## Consequences and validation
Costs, limitations, follow-up work, and how the choice will be checked.
```
